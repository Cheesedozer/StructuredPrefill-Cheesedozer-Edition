StructuredPrefill settings
Presets
Presets store StructuredPrefill behavior, prefill override text, anti-slop, and prefill-generator settings. STScript: /structuredprefill-preset "Preset Name"
General
Prefill
When unchecked, the preset's own prefill is used instead: a trailing assistant prompt in the Prompt Manager, or "Start Claude's answer with".
Anti-Slop
Case-insensitive. A word is blocked wherever a word starts with it (gaze blocks gazed and gazelle, not stargaze); punctuation like — is blocked everywhere. Multi-word phrases make the schema much larger.
Prefill Generator ([[pg]])
Used only for prefill-gen. System prompts are inserted at the top for compatibility; user/assistant prompts are appended near the end.
Some sources may remap a trailing assistant prompt to keep the request valid.
Uses the profile's API/model for prefill-gen only (does not switch your main chat API).
Tip: for best UX, end your prefill with:
[[keep]]
[[pg]]
Advanced
Normal generations only. Continue uses its own minimal constraint.
How much of the existing message the model must repeat on Continue. 0 = no overlap. [[pg]] is not used for Continue.
Only change this if your prefill literally contains the token text.
